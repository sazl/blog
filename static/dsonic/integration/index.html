Integration Guide

Complete guide to using DSonic in your projects

Overview

DSonic is a Web Audio drum synthesizer with two primary use cases:

  1. Strudel Integration - Use DSonic as a sound source in Strudel live-coding patterns
  2. Standalone Usage - Use DSonic directly in any web application via the Web Audio API
License Note: DSonic is MIT licensed. When integrating with Strudel (AGPL-3.0), the Strudel license terms apply to the combined work if you distribute it.

Architecture

DSonic provides two synthesis systems:

System Description Sound Names
Voice-based Two-layer (oscillator + noise) with waveguide resonator dsonic, dsonic_kick, dsonic_snare, etc.
Engine-based 12 specialized algorithms optimized for specific drum types dsonic_akick, dsonic_hsnare, dsonic_fmperc, etc.

Prerequisites

For Strudel Integration

  • Familiarity with Strudel pattern syntax (strudel.cc/learn)
  • Understanding of Strudel's audio architecture
  • Modern browser with Web Audio API support

For Standalone Usage

  • Node.js 18+ and npm (for npm installation)
  • ES modules-compatible bundler (Vite, webpack, esbuild, etc.)
  • Basic understanding of Web Audio API concepts (AudioContext, AudioNode)
  • TypeScript support recommended (types are included)

Strudel Integration: CDN Script

CDN Script Tag Easy

Load DSonic directly in the browser without a build step. Best for quick prototyping.

Basic Setup

Add DSonic after Strudel's scripts in your HTML:

<!-- Load Strudel REPL -->
<script src="https://unpkg.com/@strudel/repl@latest"></script>

<!-- Load DSonic -->
<script type="module">
  import { registerDSonic } from 'https://unpkg.com/dsonic@latest/dist/dsonic.js';

  // Wait for Strudel to initialize, then register DSonic
  setTimeout(() => {
    registerDSonic();
  }, 1000);
</script>

<!-- Strudel editor component -->
<strudel-editor>
s("dsonic_kick").freq(55).decay(0.3)
</strudel-editor>

Complete Example

<!DOCTYPE html>
<html>
<head>
  <title>DSonic + Strudel</title>
</head>
<body>
  <script src="https://unpkg.com/@strudel/repl@latest"></script>

  <strudel-editor id="editor">
// DSonic drum pattern
stack(
  s("dsonic_akick").freq(50).decay(0.4),
  s("dsonic_hsnare").struct("~ x").decay(0.15),
  s("dsonic_hhat*4").decay(0.05)
)
  </strudel-editor>

  <script type="module">
    import { registerDSonic } from 'https://unpkg.com/dsonic@latest/dist/dsonic.js';

    // Poll for Strudel's registerSound function
    const waitForStrudel = () => {
      if (typeof registerSound === 'function') {
        registerDSonic();
        console.log('DSonic ready!');
      } else {
        setTimeout(waitForStrudel, 100);
      }
    };
    waitForStrudel();
  </script>
</body>
</html>
Version Pinning: For production, pin DSonic to a specific version (e.g., dsonic@0.1.0) to prevent breaking changes.

Strudel Integration: npm Package

npm Installation Intermediate

Vite Configuration

// vite.config.js
import { defineConfig } from 'vite';

export default defineConfig({
  // Ensure ES modules are handled correctly
  build: {
    target: 'es2020',
  },
  optimizeDeps: {
    include: ['dsonic', '@strudel/core', '@strudel/webaudio'],
  },
});

Main Script

// src/main.js
import { registerDSonic } from 'dsonic';
import { repl } from '@strudel/repl';

// Initialize Strudel REPL
const editor = repl({
  id: 'editor',
  defaultOutput: 'speakers',
});

// Register DSonic after REPL initializes
editor.scheduler.on('ready', () => {
  registerDSonic();
});

// Set initial code
editor.setCode(`
stack(
  s("dsonic_akick").freq(55).decay(0.35),
  s("dsonic_hsnare").struct("~ x").decay(0.12),
  s("dsonic_hhat*4").decay(0.05)
)
`);

Selective Imports

For smaller bundle size, import only what you need:

// Import only specific engines

  AnalogKickEngine,

  createEngine
} from 'dsonic';

// Or import just the registration function
import { registerDSonic } from 'dsonic';

Strudel Integration: Custom REPL

Custom UI with @strudel/web Advanced

Build your own interface without Strudel's default editor. Full control over the UI.

Minimal Custom Player

import {
  getAudioContext,
  initAudioOnFirstClick
} from '@strudel/webaudio';
import {
  evaluate,
  Scheduler
} from '@strudel/core';
import { registerDSonic } from 'dsonic';

// Initialize audio on user interaction
initAudioOnFirstClick();

// Create scheduler
const scheduler = new Scheduler({
  getAudioContext,
  interval: 0.05,
  ahead: 0.15,
});

// Register DSonic sounds
registerDSonic();

// Evaluate and play pattern
async function playPattern(code) {
  const { pattern } = await evaluate(code);
  scheduler.setPattern(pattern);
  scheduler.start();
}

// Example usage
document.getElementById('play').onclick = () => {
  playPattern(`s("dsonic_akick").freq(55)`);
};

document.getElementById('stop').onclick = () => {
  scheduler.stop();
};

Adding Custom Parameters

Extend Strudel's Pattern prototype with DSonic-specific methods:

import { Pattern } from '@strudel/core';

// Add custom DSonic parameters to Pattern
const dsonicParams = [
  'bodyPitch', 'pitchEnvAmount', 'clickLevel',
  'noiseAmt', 'metalAmt', 'modIndex'
];

dsonicParams.forEach(param => {
  Pattern.prototype[param] = function(value) {
    return this.set({ [param]: value });
  };
});

Standalone Usage: API

DrumSynth (Voice-based)

The DrumSynth class orchestrates voices with shared waveguide resonator:

import {
  DrumSynth,
  getTemplateParams,
  setAudioContext
} from 'dsonic';

// Create AudioContext (must be after user interaction)
const audioContext = new AudioContext();
setAudioContext(audioContext);

// Create synth instance
const synth = new DrumSynth(audioContext);

// Trigger a kick using template
const kickParams = getTemplateParams('kick');
const { node, stop } = synth.trigger(audioContext.currentTime, kickParams);

// Trigger with custom parameters
synth.trigger(audioContext.currentTime, {
  oscillator: {
    frequency: 55,
    waveform: 'sine',
    pitchEnvAmount: 24,
    pitchEnvDecay: 0.1,
  },
  noise: {
    level: 0.2,
    type: 'white',
  },
  envelope: {
    attack: 0.001,
    decay: 0.3,
    sustain: 0,
    release: 0.1,
  },
  effects: {
    driveAmount: 0.2,
  },
});

DrumSynth Methods

Method Description
trigger(time, params, baseParams?) Trigger a voice with parameters. Returns { node, stop }
setMasterGain(gain) Set master output level (0-1)
setWaveguide(params) Configure shared waveguide resonator
stopAll() Stop all playing voices immediately
getOutput() Get the output AudioNode for routing

Standalone Usage: Engines

Engine-based synthesis provides 12 specialized drum algorithms:

Using createEngine()

import {
  createEngine,
  getAudioContext
} from 'dsonic';

const ctx = getAudioContext();

// Create an analog kick engine
const kick = createEngine(ctx, 'analog_kick', {
  bodyPitch: 50,
  bodyDecay: 0.35,
  pitchEnvAmount: 36,
  pitchEnvDecay: 0.08,
  clickLevel: 0.3,
  driveAmt: 0.2,
});

// Connect to destination
kick.getOutput().connect(ctx.destination);

// Trigger the sound
const { stop } = kick.trigger(ctx.currentTime);

// Clean up after sound finishes
setTimeout(() => kick.dispose(), 1000);

Engine Types

Type Class Use Case
'analog_kick' AnalogKickEngine 808/909-style kicks with pitch sweep
'membrane' DualMembraneEngine Physical snare with coupled membranes
'hybrid_snare' HybridSnareEngine Analog body + noise snare
'clap' ClapEngine Multi-hit handclaps
'hat' HatEngine Metallic hi-hats (closed/open)
'cymbal' CymbalEngine Crashes, rides, chinas
'tom' TomCongaEngine Toms, congas, bongos
'rim' RimClaveEngine Rimshots, claves, cowbells
'shaker' ShakerEngine Granular shakers, maracas
'fold' FoldWavetableEngine Waveshaping/wavetable drums
'karplus' KarplusEngine Karplus-Strong string/tube
'fm' FMPercEngine 4-operator FM synthesis

Direct Engine Instantiation

import {
  AnalogKickEngine,
  FMPercEngine,
  DEFAULT_ANALOG_KICK,
  DEFAULT_FM_PERC
} from 'dsonic';

const ctx = new AudioContext();

// Direct instantiation with defaults
const kick = new AnalogKickEngine(ctx, {
  ...DEFAULT_ANALOG_KICK,
  bodyPitch: 45,
  bodyDecay: 0.5,
});

// FM bell with custom algorithm
const bell = new FMPercEngine(ctx, {
  ...DEFAULT_FM_PERC,
  pitch: 440,
  modIndex: 10,
  brightness: 0.8,
  decay: 1.5,
});

kick.getOutput().connect(ctx.destination);
bell.getOutput().connect(ctx.destination);

kick.trigger(ctx.currentTime);
bell.trigger(ctx.currentTime + 0.5);

Engine Routing Example

import { createEngine } from 'dsonic';

const ctx = new AudioContext();

// Create a gain node for mixing
const masterGain = ctx.createGain();
masterGain.gain.value = 0.8;
masterGain.connect(ctx.destination);

// Create individual channel gains
const kickGain = ctx.createGain();
const snareGain = ctx.createGain();
kickGain.connect(masterGain);
snareGain.connect(masterGain);

// Trigger function with routing
function triggerSound(type, params, destination) {
  const engine = createEngine(ctx, type, params);
  engine.getOutput().connect(destination);
  const { stop } = engine.trigger(ctx.currentTime);

  // Auto-dispose after sound finishes
  const decay = params.decay || 0.5;
  setTimeout(() => engine.dispose(), (decay + 0.3) * 1000);
}

// Use it
triggerSound('analog_kick', { bodyPitch: 50 }, kickGain);
triggerSound('hybrid_snare', { decay: 0.15 }, snareGain);

Waveguide Configuration

import { setWaveguide, getDrumSynth } from 'dsonic';

// Global waveguide settings (affects all voices)
setWaveguide({
  tune: 0.5,      // 0-1, resonator pitch
  decay: 0.6,     // 0-1, feedback amount
  body: 0.4,      // 0-1, brightness
  mode: 'tube',   // 'tube' or 'string'
});

// Or configure via DrumSynth
const synth = getDrumSynth();
synth.setWaveguide({ mode: 'string', decay: 0.8 });

Master Gain

import { setMasterGain } from 'dsonic';

// Set master output level
setMasterGain(0.7); // 0-1

Troubleshooting

No Sound Output

AudioContext suspended: Browsers require user interaction before playing audio. Ensure you create/resume AudioContext in a click handler. 
document.getElementById('play').onclick = async () => {
  const ctx = getAudioContext();
  if (ctx.state === 'suspended') {
    await ctx.resume();
  }
  // Now trigger sounds
};

registerSound Not Found

This error means DSonic was loaded before Strudel finished initializing:

// Wait for Strudel's globals to be available
function waitForStrudel(callback, maxAttempts = 50) {
  let attempts = 0;
  const check = () => {
    if (typeof registerSound === 'function') {
      callback();
    } else if (attempts++ < maxAttempts) {
      setTimeout(check, 100);
    } else {
      console.error('Strudel not detected');
    }
  };
  check();
}

waitForStrudel(() => registerDSonic());

TypeScript Errors

If TypeScript can't find DSonic types:

// Ensure moduleResolution is correct
// tsconfig.json
{
  "compilerOptions": {
    "moduleResolution": "bundler" // or "node16"
  }
}

Memory Leaks

Always dispose engines after use to prevent memory leaks:

const engine = createEngine(ctx, 'analog_kick', params);
engine.getOutput().connect(ctx.destination);
const { stop } = engine.trigger(ctx.currentTime);

// IMPORTANT: Dispose after sound finishes
const decay = params.decay || 0.5;
setTimeout(() => {
  engine.dispose(); // Disconnects all nodes
}, (decay + 0.5) * 1000);

Bundle Size

For smaller bundles, import only what you need:

// Full import (~145KB)
import * as DSonic from 'dsonic';

// Selective import (smaller)
import { AnalogKickEngine, HatEngine } from 'dsonic';
